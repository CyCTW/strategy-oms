# 滑動視窗價格定位器：量測摘要

各格為各輪「每次操作 ns」中位數的中位數（輪間最小–最大）。每輪以 256 次操作為一批計時，共 160 批，取各批每次操作耗時的中位數。說明與取捨見 [sliding-window.md](sliding-window.md)，原始資料與建置資訊見 [results/sliding-window-2026-09-29-linux](results/sliding-window-2026-09-29-linux/)。

情境說明：`wN` 為 N 個連續 tick 的近價群加 2 個遠價；`rolling`/`outliers`/`jump` 為近價群移動（每次操作是一次改單送出或 ACK）；`4096books` 為 4,096 個各 6 價的小 Book；`new_books` 為每次新增一個 Book 的第一張單。
